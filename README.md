# チャットウィンドウメーカー

ココフォリアのダイスの結果や秘匿チャットを、OBS に好きなデザインで映すための「カスタム CSS」を作るツール。プレビューでメッセージを送りながら確かめられる。

**公開サイト: https://shiki365.github.io/chat-window-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要）。

マシュマロでいただいた「ダイスウィンドウや秘匿チャットを、プレビューで確かめながらカスタマイズしたい」という要望から作った。ほしいツールの要望や感想は [マシュマロ](https://marshmallow-qa.com/jisg2c3imbza76d) へ。

## できること

- **ひな形 9 種** — ダイスウィンドウ / ダイス速報（1件を大きく）/ 秘匿チャット（手紙）/ 秘匿通信（SF）/ チャットログ（背景なし）/ 吹き出し / RPG のメッセージ窓 / ホラー / 古文書
- **映すメッセージ** — 最新の件数（1〜30）、ダイスの結果だけ、システムメッセージを除く、新しいものを上か下か
- **窓** — ソースいっぱい / 中身に合わせる、寄せる位置、背景・質感（古い紙・ざらつき・走査線）・枠線・角丸・影・四隅のかっこ
- **見出し** — 自分で書いた文字、**開いているタブの名前**（秘匿タブ名がそのまま出る）、文字＋タブ名。帯・下線・見出しタブ・両側に線
- **秘匿タブの参加者** — そのタブに参加しているユーザーのアイコンを見出しの下に並べる。前に付ける文字（「宛先」など）、大きさ、間隔（重ねる）、縁取り
- **メッセージ** — カード / 吹き出し / 箱なし、左の線（キャラの色・決まった色・ダイスの成否の色）、区切り線、アイコン、名前（下線・ラベル・「名前：」）、時刻
- **文字・結果** — フォント 40 種、ふちどり、長い文を行数で切る。ダイスの結果は成功・失敗・その他で色分け、改行、枠・色の帯、光る
- **動き** — 出るときの動き 7 種、しばらくしたら消す
- プレビューでチャット・ダイス（成功 / 失敗 / 成否なし）・シークレットダイス・システムを送って確認、秘匿タブの表示に切り替え、元に戻す / やり直す、自動保存、プロジェクトファイル

## 仕組み

OBS のブラウザソースで `https://ccfolia.com/rooms/{ルームID}/chat` を開くと、ココフォリアがチャットだけの画面（ルームのチャットメニューの「別窓で表示」と同じもの）を出す。ツールが作るのは、その画面の見た目を上書きする CSS。

画面の作りは、ココフォリアの配布している JavaScript から読み取った（2026-09-15）。

```
#root > div > div.MuiDrawer-root > div.MuiDrawer-paper          （position: fixed の縦並び）
  header                          「ルームチャット」の帯（秘匿タブでは参加者のアイコンも）
  ul[role="log"]                  メッセージ一覧（仮想スクロール）
    div（高さ = 中身の合計）> div（translateY で位置合わせ）
      div[data-index]             メッセージ 1 件
        div.MuiListItem-root
          div.MuiListItemAvatar-root > div > .MuiAvatar-root > img     （システムは空の div）
          div.MuiListItemText-root
            span.MuiListItemText-primary（style="color: キャラの色"）  名前 + 時刻
            p.MuiListItemText-secondary   本文 + span.css-xxxx（ダイスの結果）
        hr
  div.MuiPaper-root > form > header … [role="tab"][aria-selected]      タブ、その下に入力欄
```

- **最新 N 件だけ映す** — N 件より古いメッセージを `display: none` にする。ココフォリアの仮想スクロールは隠れたものを 0px と測るので、表示範囲が必ず最新まで届く（前後 50 件ぶん描画するので、N は 30 まで）。一覧はスクロールさせず、flex の揃え方で古い側がはみ出して切れるようにしている
- **一覧は最低 1px の高さを残す** — 仮想スクロールは一覧の高さが 0 だとメッセージを 1 件も描かず、そのまま大きくならない。「中身の大きさに合わせる」窓で OBS に何も映らなかった原因（2026-09-15、OBS で確認）
- **ダイスだけ** — `:nth-last-child(-n+N of :has(結果の span))`。OBS 31（Chromium 127）以降。古い OBS ではこの行が捨てられて、ふつうの最新 N 件になる
- **成功・失敗の色** — 結果の span は MUI の Typography で、色は emotion のクラス（`css-` + スタイルのハッシュ）で付く。本体 JS のハッシュ関数で計算し、既存の配信用 CSS が使っているクラス名と一致することを確かめた
  - 成功 `css-1l6qhgm`（body2 + primary #2196f3）/ 失敗 `css-1j13mke`（body2 + secondary #dc004e）/ その他 `css-ucj12`（body2 + text.secondary）
  - ほかの人のシークレットダイスは結果の span が無く、本文が「Secret dice 🎲」になる
- **キャラの色で線を引く** — 名前の `color` はキャラの色のまま残し、文字は `-webkit-text-fill-color` で塗る。名前の疑似要素が `currentColor` で箱の左に線を引く
- **タブ名の見出し** — 入力欄の上のタブのうち、`.MuiTab-root.Mui-selected` だけを残して見出しにする。メイン以外のタブは並べ替え用の dnd-kit が `role` を `button` に書き換えるので、`[role="tab"]` では探せない
- **参加者のアイコン** — 参加者を決めた秘匿タブを開くと、ヘッダーに 2 つ目の Toolbar（`header > .MuiToolbar-root:not(:first-child)`、中に `.MuiAvatarGroup-root`）が**包まれずに直接**入る。アイコンはユーザーのプロフィール画像。見出しがタブ名のときはヘッダーのうちこの Toolbar だけを出し、`order` で見出しの下に置く
- **タブの選び方** — `html:hover` のときだけタブを出す。OBS の「対話」でマウスを乗せたときだけ効き、配信には出ない。タブの選択（`roomChatTab`）はココフォリアが保存しないので、読み込み直すとメインに戻る
- プレビュー（`mock.v1.js`）はココフォリア側の元のスタイル（content-box、背景 #202020、仮想スクロールの高さ指定など）も再現していて、CSS が上書きし忘れたものはプレビューでも崩れて見える

## 増やし方

- **ひな形** — `presets.v1.js` の `DESIGNS` に 1 つ足す。`BASE_LOOK` に対する差分だけ書けばよい
- **出るときの動き** — `presets.v1.js` の `ENTERS` に名前を、`css.v1.js` の `ENTER_FRAMES` にキーフレームを足す
- **フォント** — `presets.v1.js` の `FONTS` に足す。`weights` は Google Fonts に実在する太さだけにする

## 気をつけること

- OBS 32.2.2 と本物のテスト用ルームで確認済み（2026-09-15）: ダイスだけ最新 N 件の入れ替わり、成否の色、時間で消える、秘匿タブ名の見出しと秘匿タブのメッセージ、「対話」でマウスを乗せたときだけタブが出て閉じると消える、読み込み直すとタブがメインに戻る
- ココフォリアの画面の作りやテーマの色が変わると、表示が崩れたり成否の色分けが効かなくなったりすることがある
- Google Fonts を使うので、OBS の PC がインターネットにつながっている必要がある
- 秘匿タブは、そのタブに参加しているアカウントでログインしたときだけ見える
